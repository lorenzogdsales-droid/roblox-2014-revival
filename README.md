# 🎮 Roblox 2014 Revival

Recriação da interface e servidor do Roblox 2014 para Android com servidores modificados.

## 📋 Características

- ✅ Interface azul clássica de 2014
- ✅ Abas: Play, Games, Profile, Chat
- ✅ Servidor multiplayer customizado
- ✅ App Android (APK)
- ✅ Sistema de autenticação
- ✅ Chat em tempo real

## 📁 Estrutura

```
roblox-2014-revival/
├── android/              # App Android
│   ├── app/
│   ├── app.apk
│   └── AndroidManifest.xml
├── server/               # Backend Node.js
│   ├── src/
│   ├── package.json
│   └── server.js
├── assets/               # Imagens e recursos
│   ├── ui/
│   └── logos/
└── docs/                 # Documentação
```

## 🚀 Como usar

### Android
1. Instale o APK em seu dispositivo
2. Abra o app
3. Faça login ou crie uma conta

### Servidor
```bash
cd server
npm install
node server.js
```

## ⚙️ Configuração

Edite `server/config.json` com as configurações de seu servidor.
