# Changelog - GameOS

## [1.0.0] - 2026-09-13

### 🎉 Initial Release

#### Added
- ✨ Interface principal com seleção de modo
- 🧪 Modo Teste (Sandbox) com emulação isolada
- 🔧 Modo Instalação para sistemas reais
- 💾 Sistema de persistência de progresso
- 📊 Histórico de instalações
- 🔐 Isolamento completo do modo teste
- 🤖 Suporte para Linux, Windows e Android
- ⚙️ CI/CD com GitHub Actions
- 📱 APK compatível com Android 7.0+

#### Technical
- Kotlin + Java
- Android SDK 34
- Gradle Build System
- Room Database
- Coroutines for async operations

#### Known Limitations
- Emulação de SO ainda não implementada
- Instalação real ainda em desenvolvimento
- Interface básica, sem temas avançados
