# 📱 Roblox 2014 Revival - Android

App Android com interface clássica azul de 2014.

## 📲 Instalação

1. Baixe o arquivo `app.apk`
2. Habilite instalação de fontes desconhecidas
3. Instale o APK

## 🎨 Interface

- **HOME**: Tela inicial com logo Roblox azul
- **PLAY**: Acesso aos servidores disponíveis
- **GAMES**: Lista de jogos
- **PROFILE**: Perfil do usuário
- **CHAT**: Mensagens em tempo real

## 🔧 Desenvolvimento

Para compilar do zero:

```bash
cd android
gradlew build
```

## 📋 Requisitos

- Android 5.0+
- Conexão com internet
