# 🔨 Compilação do APK - Roblox 2014 Revival\n\n## Pré-requisitos\n\n- ✅ Android SDK (API 33)\n- ✅ Gradle 7.0+\n- ✅ JDK 11+\n- ✅ Git\n\n## Instruções de Compilação\n\n### 1. Clonar o Repositório\n\n```bash\ngit clone https://github.com/lorenzogdsales-droid/roblox-2014-revival.git\ncd roblox-2014-revival/android\n```\n\n### 2. Compilar Release APK\n\n```bash\n./gradlew assembleRelease\n```\n\n### 3. Localizar o APK\n\nO APK compilado estará em:\n```\nandroid/app/build/outputs/apk/release/app-release.apk\n```\n\n### 4. Assinar o APK (Opcional mas Recomendado)\n\n```bash\njarsigner -verbose -sigalg SHA1withRSA -digestalg SHA1 \\\n  -keystore my-release-key.keystore \\\n  app/build/outputs/apk/release/app-release.apk \\\n  alias_name\n```\n\n### 5. Instalar em Dispositivo\n\n```bash\nadb install app/build/outputs/apk/release/app-release.apk\n```\n\n## Resultado\n\n- 📦 **APK Limpo**: Sem referências de desenvolvimento\n- 🔒 **Ofuscado**: Código protegido com ProGuard\n- ⚡ **Otimizado**: Tamanho reduzido\n- 🎮 **Pronto para Produção**: Pode ser distribuído\n\n## Verificação\n\nPara verificar se o APK foi gerado corretamente:\n\n```bash\nfile app/build/outputs/apk/release/app-release.apk\n```\n\nDeve retornar: `Zip archive data`\n\n## Troubleshooting\n\n### Erro: \"SDK not found\"\n```bash\nexport ANDROID_HOME=/caminho/para/android-sdk\nexport PATH=$PATH:$ANDROID_HOME/tools:$ANDROID_HOME/platform-tools\n```\n\n### Erro: \"Gradle build failed\"\n```bash\n./gradlew clean\n./gradlew assembleRelease\n```\n\n### Erro: \"Could not determine android.compileSdkVersion\"\nEdite `build.gradle` e verifique se a API 33 está instalada.\n"
